Auxiliaries

This page covers the supporting tools and utilities that operate alongside the framework.

Jenova MSVC Packer Wizard​

Jenova MSVC Packer Wizard is a lightweight, high‑performance packaging tool built on top of the Jenova Wizard Framework (JWF)
Its purpose is to generate a fully‑portable Microsoft Compiler packages from any official local installation of Microsoft Visual C++ Build Tools.

Since Microsoft Visual C++ Build Tools are not redistributable, this tool lets users create their own JenovaMSVCCompiler package locally.

Features​

  • Cinematic UI, GPU‑accelerated effects and ultra‑fast execution.
  • Full DPI support, crisp scaling on high‑resolution displays.
  • Automatically detects MSVC and Windows SDK paths.
  • Validates directory integrity and version compatibility.
  • Collects, filters and debloats headers, libraries and optional debug symbols.
  • Generates metadata and structured output directories.
  • Produces a compact, portable compiler package suitable for Jenova build systems.

Usage​

  1. Download the wizard from here. (Jenova.MSVC.Packer.Win64.exe/2.12 MB 📥)
  2. Run the wizard and configure the MSVC Build Tools and Windows SDK paths.
  3. Wait for the wizard to finish packaging. If possible, use NVMe storage for best performance.
  4. Copy the generated package to your Jenova local package repository or install it using your custom package installer.
