Welcome

Welcome to the official API reference documentation of JenovaSDK, this reference guide provides a detailed overview of all the functions and utilities available within the development kit.

JenovaSDK offers a comprehensive set of functions to simplify development within the Jenova Framework. Key features include:

  • Utility functions for formatting, printing and debugging etc.
  • Functions for accessing engine state, scene tree and nodes etc.
  • Functions for tracking asset changes and runtime events.
  • Functions for performance checkpoints and profiling.
  • Type casting and pointer access utilities
  • Variable and string conversion functions
  • Callback registration and icon management
  • Graphic utilities for accessing game window handles and rendering devices
  • Memory management functions for global memory and variables
  • Hot-reloading functions to activate, store and restore node states etc.
  • Task system functions for multi-threaded task creation and management
  • Real-time C Scripting functions to execute Clektron scripts, register symbols etc.
  • Wrapped template functions for accelerated development through code minimization.
