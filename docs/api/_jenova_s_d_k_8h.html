enum RuntimeEvent

Enumerates the different Jenova Runtime events.

Enumerator
Initialized 

The runtime was initialized.

Started 

The runtime was started.

Stopped 

The runtime was stopped.

Ready 

The runtime is ready.

EnterTree 

The runtime entered the tree.

ExitTree 

The runtime exited the tree.

FrameBegin 

The frame began.

FrameIdle 

Idle frame (deferred tick) processed.

FrameEnd 

The frame ended.

FramePresent 

The frame was presented.

The process was called.

The physics process was called.
