Nodle
Container
for Godot Engine

Layout your UI and game interfaces with a modern, responsive and declarative syntax inspired by CSS. Lightning fast, reactive and perfectly integrated into Godot Engine.

# Nodle Layout Example
[@mode Wide]
max-width: 720px

[ColorRect]
position: absolute
left: 0
top: 0
width: 50%
height: 100%

[TextureRect]
position: absolute
left: 50%
top: 0
width: 50%
height: 100%

Built for Production

Feels like CSS but fully optimized for Godot nodes.

CSS-Like Syntax

Nodle Markup follows a familiar CSS-like syntax, allowing you to directly apply layouts by referencing child nodes.

Responsive

Support for media queries and viewport units. Your game UI adapts to any resolution from desktop to mobile instantly.

Smooth Tooling

Nodle includes a syntax highlighter, custom inspector, and supports editor's 2D viewport, all in real-time!
