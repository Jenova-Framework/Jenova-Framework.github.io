MeshInstanceEx3D

An improved version of MeshInstance3D with fast yet accurate UV lookup and texture sampling, two convenient features that are frequently needed in any game engine!

Download NowWatch Tutorial
Windows · Linux · Android · Web

Core Capabilities

Heavily-Optimized

A hybrid optimization approach that combines brute-force for low-poly meshes and spatial partitioning for high-poly meshes.

Highly Accurate

When optimization techniques are applied, the computation yields highly accurate and error-free results.

Universal API

Native support for third-party languages including GDScript, .NET (C#), GDExtension (C++), Dart, Gravity and more.
