PROJEKT J.E.N.O.V.A
Ultimate C++ Scripting Solutions

Project J.E.N.O.V.A was launched in 2024 with a bold vision, to transform Godot Engine into a high-end engine by harnessing cutting-edge technologies.
At its core lies the Jenova Runtime, a fully-featured C++ scripting backend that elevates C/C++ language to a first-class citizen within the engine.

Since its inception, it has consistently pushed the boundaries, introducing innovative features that streamline development across various fields. From crafting desktop applications to creating high performance AAA-quality video games, the project has made significant strides in making C++ development more accessible and efficient.

C/C++ Scripting • Emulation • Package Manager • Debug/Profiling Tools • Stable Hot-Reload • Unmatched Tooling and more.

Jenova Framework - Ultiamte C++ Scripting Solutions for Godot Engine

Native C++ Scripting

Enjoy a fully-featured C++ scripting backend, implemented natively just like GDScript, C#, etc.

Property/Signal Support

Jenova C++ Scripts support properties and signals natively, you can expose as much as you want!

C++ Syntax Highlighter

Jenova provides in-editor code editing tools such as a dedicated syntax highlighter, build pipeline, etc.

Comprehensive Tooling

Various tools & helpers to streamline C++ development and make it more accessible than ever!

IDE Integration

Use any IDE you like, Jenova supports Visual Studio, VSCode, Code IDE, CLion & Neovim natively!

Debugging/Profiling Tools

Jenova provides dedicated debugging & profiling tools to help you achieve the best performance!

Heavily Customizable

Tweak everything from Editor Settings to compiler options, giving you full control over your workflow.

Dedicated Terminal

A dedicated terminal keeps build messages separate from game output, preventing log interference.

Built-in Package Manager

Jenova has a dedicated package manager to install any required addon, compiler, sdk, tool easily.

Future Functions

Schedule any function for future execution & easily access the main-thread from any third-party context.

Stable Hot-Reloading

Hot-Reload editor/runtime scripts & Nested Extensions using the Sakura Hot-Reload System.

Nested Extensions

Develop extension Nodes, Resources, Tools and Plugins directly in C++ with hot-reload support!

Deep Integration

You can use all the C++ functions in UI, Animation Player and Cross-call from any third-party language.

Developer Console

Test your game logic, spawn entities, and debug using the Developr Console, powered by Clektron.

Clektron aka Electron-C

A fast & minimal C-powered scripting language designed for runtime deployment and system design.

Blade Meta-Language

A high-performance, cross-platform, fully-featured meta-language powered by Pure C.
